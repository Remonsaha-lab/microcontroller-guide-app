Electrical Operation Principle:

When door is CLOSED, magnet holds switch closed $\rightarrow$ PA5 is hard-grounded ($0\text{ V}$, logic 0).
When door OPENS, magnet moves away, switch opens $\rightarrow$ internal $30\text{ k}\Omega$ pull-up resistor pulls PA5 cleanly to $+5\text{ V}$ (logic 1), triggering the PC7 alarm!

// Tutorial 7: Door Alarm with Pull-Up & Reed Switch void setup() { DDRA &= ~(1 << 5); // Configure PA5 as INPUT PORTA |= (1 << 5); // Enable internal 20k-50k pull-up resistor DDRC |= (1 << 7); // Configure PC7 as OUTPUT (Alarm Siren) } void loop() { if (PINA & (1 << 5)) { PORTC |= (1 << 7); // Door OPEN -> PA5 pulled HIGH -> ALARM ON } else { PORTC &= ~(1 << 7); // Door CLOSED -> PA5 grounded -> ALARM OFF } }

Full Adder Inputs
Minterm Mapping:
$$S = \Sigma m(1, 2, 4, 7) = P_1 + P_2 + P_4 + P_7$$
$$C_{out} = \Sigma m(3, 5, 6, 7) = P_3 + P_5 + P_6 + P_7$$
Why Diode AND + Transistor OR?

In a diode AND matrix, lines are pulled HIGH to $+V_{CC}$ via resistors. If ANY connected input rail is LOW ($0\text{V}$), the diode conducts forward, clamping the product line to $\approx 0.7\text{V}$ (Logic 0). Only when ALL inputs are HIGH do the diodes reverse-bias, allowing the line to reach $+5\text{V}$ (Logic 1).

Class Test Theory: Merits & Demerits of SRAM
  • Merits: Extreme access speed ($5\text{--}15\text{ ns}$), infinite read/write endurance, standard CMOS fabrication compatibility.
  • Demerits: Volatile (loses state on power loss), large silicon area per bit ($6\text{ transistors}$ vs $1\text{T}-1\text{C}$ DRAM), static leakage power dissipation.

Class Test Theory: Why FPGAs Use Transmission Gates

When routing digital signals across an FPGA's programmable routing matrix, an NMOS transistor passes a logic 0 ($0 ext{V}$) with zero attenuation, but cannot pass a logic 1 ($5 ext{V}$) higher than $V_{DD} - V_{th} = 4.3 ext{V}$.

By pairing NMOS in parallel with PMOS (driven by complementary control $S$ and $\overline{S}$), the PMOS device conducts strongly at high voltages, pulling the output all the way up to $V_{DD} = 5.0 ext{V}$. This ensures zero signal loss through multiple routing hops!
